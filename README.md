# Atlases of Cyclic Composition Mosaics

A collection of comprehensive cartographic monographs, algebraic classifications, and discrete geometry atlases exploring cyclic lattices, polygon orbits, and composition mosaics on $\mathbb{Z}_n$.

## Volumes

1. **`polyatlas/` — The Polygonal Cauchy--Frobenius**
   * An exhaustive atlas and algebraic classification of all dihedral orbits of inscribed single polygons from $\mathbb{Z}_1$ to $\mathbb{Z}_{16}$, evaluated via the Cauchy--Frobenius bracelet generating polynomial $CF_n(x)$.
   * Includes machine-readable datasets (`inngons.tsv`, `inngons.csv`, `inngons.json`), generative TikZ pipelines, and canonical circular stride classifications.
